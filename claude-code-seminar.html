1. Claude Code とは？
3つの「Claude」、何が違う？
中身のAI（モデル）は同じ。どこで動くか・何ができるかが違う
💬
Claude.ai
（Web版）
「考える」ためのClaude
例えるなら：賢い相談相手
🖥️
Claude Cowork
（デスクトップアプリ）
「作業する」ためのClaude
例えるなら：パソコンの中の同僚
⚡
Claude Code
（CLI / アプリ）
「作る」ためのClaude
例えるなら：あなた専属のプログラマ
💡 Pro プラン（月22ドル〜）1本で、3つすべて使えます。

1. Claude Code とは？
🖥️
Claude Cowork
あなたのPCの中で「代わりに作業してくれる」Claude
🖥️
形態
デスクトップアプリ（Mac / Windows）
👤
向いている人
コードを書かない知識労働者（事務、企画、リサーチ系）
🛠️
できること
  • ローカルのファイル・フォルダを読み書き
  • Google Drive / Gmail などの業務ツールと連携
  • 「毎朝メールをチェックして要約」など定期実行
  • 複数アプリをまたぐ作業を自動で完遂
💡 使い方のイメージ：「これお願い」と頼んだら、結果のファイルが返ってくる。
会話ではなく 委任。

  • スキル・MCP・Sub Agent で自由に拡張
💡 使い方のイメージ：日本語で指示すれば、PC上の作業をほぼ何でも代行してくれる

4. 使う上での制約・注意点
知っておきたい3つのこと
「便利」と「リスク」は表裏一体
💰

定額プランでも上限あり（Pro / Max 5x / Max 20x）。

🔐
セキュリティ
ファイル書き換え・コマンド実行を勝手にやるリスクあり。
権限モードで許可範囲を制御する。
🔒
データの扱い
関係者外秘（未公開物件情報）・個人情報（プロフィールシート）を入力していいか、
AIの学習に利用されるリスクあり。
迷ったら入れない。またはマスキングする。
5. 便利な使い方
こんな使い方があります
インストールが終わったら、ぜひ挑戦してほしいこと
🖥️ ① 常時起動するPCを作成する
  • Dispatch を使えば、スマホから Cowork を呼び出して利用できる
  • 多くの人は Mac mini（品薄）。Windows PC でも OK！
  • ローカルファイルを使うので、1つの環境にまとめるのが効率的
  • 常時起動PCへは、Windows リモートデスクトップ や Chrome リモートデスクトップ でログイン
📚 ② Obsidian に情報をまとめる
ローカルのMarkdownファイルを Claude Code から読み書きできるので、知識ベース構築 と相性抜群。
⏰ ③ スケジュール実行 / MCP 連携
「毎朝7時に〇〇」「毎週月曜に〇〇」を自動化。MCP サーバーを追加すれば、Notion・Slack・Calendar などとも連携。
